Enigma Performance Guide
1. 6-Digit Code Formula:
• Digit 1: Length of word (3–9, 0=10, 1=11+)
• Digit 2: Position of 1st vowel (1–9)
• Digit 3: Position of 2nd vowel (or 0 if only 1 vowel)
• Digits 4 & 5: 0 0 (standard wildcards)
• Digit 6: First letter capital shape:
  • 1 = Straight lines only (A, E, F, H, I, K, L, M, N, T, V, W, X, Y, Z)
  • 2 = Straight + Curves (B, D, G, J, P, R, U)
  • 3 = Curves only (C, O, Q, S)
  • 0 = Skip shape (matches all words of that length & vowels)
2. Performance Examples:
• SPOON: 5 3 4 0 0 3 (5 letters, vowels at 3 & 4, S is curved)
• LIGHTER: 7 2 6 0 0 1 (7 letters, vowels at 2 & 6, L is straight)
• GLASS: 5 3 0 0 0 2 (5 letters, vowel at 3, G is mixed)
3. Secret Controls:
• Reset Screen: Double-tap or long-press ANY of the 4 corners at any time.
• Category Sheet: Tap "Emergency" to discreetly select category.
• Homescreen Reveal: If multiple words match, phone unlocks to fake homescreen with clean white text words at top and letters at bottom. Tap letter to filter, tap word to launch Safari Google Search.
4. Lexicon Voice & Ouija Dot Branching:
• When multiple words match, a discreet Yellow Dot appears on one of the top 4 app icons indicating which letter to ask about:
  • Icon 1 (FaceTime) → 1st letter
  • Icon 2 (Calendar) → 2nd letter
  • Icon 3 (Photos) → 3rd letter
  • Icon 4 (Camera) → Last letter
• Have the spectator name a clue word starting with that letter (or name the object directly).
• Say: "[word] interesting..." (e.g. "A gun, that's interesting" or "Gun, interesting"). The phone detects the clue word, resolves the exact target word, gives a discreet haptic buzz, turns off the yellow dot, and updates Notes/Safari!
